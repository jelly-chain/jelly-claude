# dexscreener-scanner

Discover new token pairs, monitor prices, and surface trending tokens across all chains via DexScreener.

## Activate
```
/agent dexscreener-scanner
```

## Required setup
1. Install `dexscreener-skill`:
   ```bash
   bash ../jelly-claude-skills/skills/dexscreener-skill/install.sh
   ```
2. No API key required — DexScreener is fully public.
