# birdeye-analyst

Token analytics, trending tokens, holder analysis, and wallet P&L via Birdeye API.

## Activate
```
/agent birdeye-analyst
```

## Required setup
1. Install `birdeye-skill`:
   ```bash
   bash ../jelly-claude-skills/skills/birdeye-skill/install.sh
   ```
2. Get a free API key at [birdeye.so](https://birdeye.so) (Starter tier: 100 req/min)
3. Add to `~/.jelly-claude/.keys`:
   ```
   BIRDEYE_API_KEY=your_key_here
   ```
