CLI Modules

Run anything from the terminal.

No Claude session needed — every module is a standalone CLI tool.

Bash Copy
# Predict a signal (Jelly Score 0–100)
$ node modules/market/run.mjs predict --text "Solana TVL surge" --chain solana

# Scan new tokens on BNB Chain
$ node modules/scanner/run.mjs newTokens --chain bsc --maxAge 30

# Cross-platform arbitrage detection
$ node modules/prediction-markets/run.mjs arbitrage --query "BTC"

# Portfolio snapshot
$ node modules/portfolio/run.mjs snapshot --solana

# DeFi yield search
$ node modules/defi/run.mjs yields --chain solana --minApy 20

# Bridge route comparison
$ node modules/bridge/run.mjs fees --fromChain 1 --toChain 56

Get Started

Up and running in 60 seconds.

Mac / Linux

Bash
# Clone the repo
$ git clone https://github.com/jelly-chain/jelly-claude
$ cd jelly-claude

# Run the setup wizard (one time only)
$ bash setup.sh

# Add your API key to .env
$ nano .env

# Launch the agent
$ bash jelly-claude.sh

# Or launch in TORQ mode (best performance per token)
$ bash torq.sh

Windows (PowerShell)

PowerShell
# If you get an execution policy error, run first:
PS> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

PS> git clone https://github.com/jelly-chain/jelly-claude
PS> cd jelly-claude
PS> .\setup.ps1
PS> .\jelly-claude.ps1

API Key — which one to use?

🅰️ Anthropic (recommended)

Best quality, requires a paid account.

ANTHROPIC_API_KEY=sk-ant-...

🅱️ OpenRouter (free/low-cost)

Works with free or cheap models. Jelly auto-configures model tiers.

OPENROUTER_API_KEY=sk-or-...
