# jelly-arbitrage

> Cross-market, cross-exchange, and cross-chain arbitrage intelligence powered by Claude Code.

**GitHub:** [github.com/jelly-chain/Extension/jelly-arbitrage](https://github.com/jelly-chain/Extension/jelly-arbitrage)

---

## What is this?

jelly-arbitrage is a Claude Code extension that:
- Installs **6 skills** covering CEX, DEX, prediction markets, and perpetuals for comprehensive price comparison
- Loads **6 agent templates** for CEX/DEX arb, prediction market arb, funding rate arb, and statistical arb
- Includes `CLAUDE.md` — session memory pre-loaded with skill paths and key references
- Works with Anthropic paid models or free/cheap OpenRouter models

---

## Skills included

| Skill | What it covers |
|-------|---------------|
| `polymarket-skill` | Polymarket CLOB prices (Polygon/USDC) |
| `kalshi-skill` | Kalshi binary market prices (US regulated, USD) |
| `predict-fun-skill` | predict.fun CLOB prices (BNB/USDT) |
| `hyperliquid-skill` | Hyperliquid perp funding rates and mark prices |
| `okx-skill` | OKX CEX spot + perp prices and funding rates |
| `1inch-skill` | Best DEX prices across 300+ sources for token arb |

## Agents included

| Agent | What it does |
|-------|-------------|
| `cross-market-arb-hunter` | Find YES/NO price divergences across Polymarket, Kalshi, predict.fun |
| `cross-exchange-arb` | Spot price gaps between OKX, Hyperliquid, and DEXes |
| `funding-rate-arb` | Exploit funding rate gaps between Hyperliquid and OKX perps |
| `dex-arb-scanner` | Find price inefficiencies across Uniswap, PancakeSwap, Raydium |
| `statistical-arb` | Mean-reversion trades on correlated asset pairs |
| `bridge-arb` | Exploit token price gaps between chains via bridges |

## Safety rules for arbitrage

- **Always verify net spread after fees** — Polymarket (2%), Kalshi (varies), predict.fun (~1%)
- **Check liquidity on both legs** before sizing — thin books mean you may not fully fill
- **Prediction market arb has execution lag** — price can move before both legs fill
- **CEX/DEX arb is competitive** — bots compete; use low-latency execution
- **Never commit more than 10% of capital to a single arb position**
