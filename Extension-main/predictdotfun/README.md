# predict-fun-skill

Teach your Jelly agent to browse, analyze, and trade on **[predict.fun](https://predict.fun)** — a live CLOB binary prediction market on BNB Chain, settled in USDT.

## What predict.fun is

predict.fun is the primary BNB Chain prediction market. It works like Polymarket (Polygon/USDC) but runs on BSC with USDT collateral. Markets are binary YES/NO contracts that resolve via the UMA Optimistic Oracle. You trade by posting limit or market orders against a Central Limit Order Book.

## Prerequisites

Before the agent can trade you need:

| Requirement | How to get it |
|-------------|--------------|
| BNB Chain wallet | Auto-generated by jelly-claude `setup.sh` — check `~/.jelly-claude/.keys` for `EVM_PRIVATE_KEY` |
| BNB for gas | ~0.01 BNB — send to your wallet from any exchange |
| USDT on BNB Chain | Buy on Binance and withdraw to BNB Chain, or swap on PancakeSwap |
| predict.fun API key | Join Discord → https://discord.gg/predictdotfun → open a **#support-ticket** and request an API key. Free for developers. |
| Node.js 18+ | For the TypeScript SDK |

> **No API key needed on testnet.** Use `api-testnet.predict.fun` to practice for free.

## Install this skill

**Mac / Linux:**
```bash
bash ./install.sh
```

**Windows (PowerShell):**
```powershell
.\install.ps1
```

The installer copies `SKILL.md` into `~/.claude/skills/predict-fun-skill/` and registers it in `~/.claude/CLAUDE.md` so Claude picks it up automatically on the next session start.

## Add your keys

Copy `.keys.example` into your Jelly keys file and fill in your values:

```bash
cp .keys.example ~/.jelly-claude/.keys
# then edit ~/.jelly-claude/.keys and fill in:
#   EVM_PRIVATE_KEY       — your BNB Chain wallet private key
#   PREDICT_API_KEY       — from the Discord support ticket
```

If you use the predict.fun web app and want to trade with your in-app Smart Wallet:
```
PRIVY_WALLET_PRIVATE_KEY  — export from predict.fun/account/settings
PREDICT_ACCOUNT_ADDRESS   — your deposit address from predict.fun/account/settings
```

## Install the TypeScript SDK

```bash
npm install @predictdotfun/sdk ethers
```

## Set one-time approvals

Before your first trade, run this once per wallet:

```typescript
import { Wallet } from "ethers";
import { OrderBuilder, ChainId } from "@predictdotfun/sdk";

const signer  = new Wallet(process.env.EVM_PRIVATE_KEY!);
const builder = await OrderBuilder.make(ChainId.BnbMainnet, signer);
await builder.setApprovals(); // sends 4 approval txs, needs ~0.01 BNB gas
```

Or just ask the agent: **"Set up my predict.fun approvals"** and it will handle this step.
