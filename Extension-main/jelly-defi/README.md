# jelly-defi

> DeFi yield optimization, lending strategy, liquidity provision, and protocol analytics powered by Claude Code.

**GitHub:** [github.com/jelly-chain/Extension/jelly-defi](https://github.com/jelly-chain/Extension/jelly-defi)

---

## What is this?

jelly-defi is a Claude Code extension that:
- Installs **6 skills** covering lending, DEX trading, yield aggregation, and analytics
- Loads **6 agent templates** for yield farming, borrowing strategy, liquidity management, and risk monitoring
- Includes `CLAUDE.md` — session memory that pre-loads skill paths and API key locations
- Works with Anthropic paid models or free/cheap OpenRouter models

---

## Skills included

| Skill | What it covers |
|-------|---------------|
| `aave-skill` | Aave V3 lending, borrowing, flash loans across 6 chains |
| `defillama-skill` | Protocol TVL, yield pools, stablecoin pegs, bridge flows |
| `uniswap-skill` | Uniswap V3 swaps, pool data, concentrated liquidity positions |
| `1inch-skill` | Best-rate DEX aggregation across 300+ sources |
| `chainlink-skill` | On-chain price feeds for position health checks |
| `coingecko-skill` | Token prices, market caps, trending coins |

## Agents included

| Agent | What it does |
|-------|-------------|
| `defi-yield-optimizer` | Find the best yield for any token across all protocols |
| `lending-strategist` | Optimize borrow/supply positions on Aave, Compound, Morpho |
| `lp-manager` | Manage Uniswap V3 concentrated liquidity ranges and rebalance |
| `yield-harvester` | Auto-compound farming rewards and reinvest to maximize APY |
| `defi-risk-monitor` | Track protocol TVL, audit scores, oracle health, and whale exits |
| `stablecoin-optimizer` | Find safest + highest yield stablecoin positions |

## Quick Start

```bash
git clone https://github.com/jelly-chain/Extension/jelly-defi
git clone https://github.com/jelly-chain/Extension/jelly-defi-skills
git clone https://github.com/jelly-chain/Extension/jelly-defi-agents

cd jelly-defi
bash setup.sh
bash jelly-defi.sh
```

## Windows

```powershell
.\setup.ps1
.\jelly-defi.ps1
```

## Keys needed

| Key | Source |
|-----|--------|

| `ONEINCH_API_KEY` | portal.1inch.dev |
