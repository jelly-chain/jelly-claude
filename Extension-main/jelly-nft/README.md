# jelly-nft

> NFT analytics, floor sweeping, rarity sniper, and collection intelligence powered by Claude Code.

**GitHub:** [github.com/jelly-chain/Extension/jelly-nft](https://github.com/jelly-chain/Extension/jelly-nft)

---

## What is this?

jelly-nft is a Claude Code extension that:
- Installs **5 skills** covering NFT marketplaces, analytics, pricing, and on-chain token data
- Loads **5 agent templates** for flipping, collection research, rarity sniping, portfolio tracking, and arbitrage between marketplaces
- Includes `CLAUDE.md` — session memory that pre-loads API key locations and skill paths
- Works with Anthropic paid models or free/cheap OpenRouter models

---

## Skills included

| Skill | What it covers |
|-------|---------------|
| `opensea-skill` | OpenSea V2 API — listings, offers, sales, buy/sell, collection stats |
| `etherscan-skill` | On-chain NFT transfer history, ownership checks, contract verification |
| `coingecko-skill` | ETH price, gas cost context, market conditions for NFT timing |
| `chainlink-skill` | On-chain price feeds for fair-value NFT pricing in USD |
| `birdeye-skill` | Cross-chain token analytics to assess project treasury health |

## Agents included

| Agent | What it does |
|-------|-------------|
| `nft-flipper` | Monitor floor, bid below floor, list above for profit |
| `rarity-sniper` | Find underpriced rare traits in recently listed NFTs |
| `collection-researcher` | Deep-dive collection fundamentals: team, roadmap, holder distribution |
| `nft-portfolio-tracker` | Track all NFT holdings, unrealised gains, and floor value |
| `marketplace-arb` | Find price gaps for the same NFT across OpenSea and Blur |

## Quick Start

```bash
git clone https://github.com/jelly-chain/Extension/jelly-nft
git clone https://github.com/jelly-chain/Extension/jelly-nft-skills
git clone https://github.com/jelly-chain/Extension/jelly-nft-agents

cd jelly-nft
bash setup.sh
bash jelly-nft.sh
```

## Windows

```powershell
.\setup.ps1
.\jelly-nft.ps1
```

## Keys needed

| Key | Source |
|-----|--------|
| `OPENSEA_API_KEY` | https://docs.opensea.io/reference/api-keys |
| `EVM_PRIVATE_KEY` | auto-generated by jelly-claude setup.sh |
| `ETH_RPC_URL` | Alchemy or Infura |
